# 批量图片压缩（画质把关版）

目标：一次压一整个文件夹的 PNG/JPG，体积尽量小，但肉眼看不出变化；任何一张压坏或变大都退回原图。

## 0. 先问清（只问一次）
- 图片在哪个文件夹？要不要保留子目录结构？
- 选档位：**高质量**（默认，几乎无损）/ **均衡**（约 TinyPNG 水平）/ **极限**（最小，适合背景大图）。
- 输出到新文件夹，**永远不覆盖原图**。

## 1. 准备工具
需要本机已安装（本 skill 不打包它们，各自许可证见 README）：
`pngquant`、`oxipng`、`mozjpeg`（`cjpeg`/`jpegtran`）、`dssim`。
- macOS：`brew install pngquant oxipng mozjpeg dssim`
- 缺哪个先装哪个，装不上就告诉用户，不要换成在线压缩网站上传图片。

**PNG：** pngquant 量化 → 用 dssim 和原图比 → 达标再 `oxipng -o 4 --strip safe`。
不达标依次退回：加满抖动重试 → 仅无损 oxipng → 保留原图。

**JPG：** mozjpeg 重编码（基线顺序编码，兼容性好）→ dssim 把关 → 不达标逐级提高质量 → 仍不行保留原图。带 EXIF 旋转的 JPG 直接保留原图。

**档位参数：**
| 档位 | PNG 质量 | 抖动 | DSSIM 上限 | JPG |
|---|---|---|---|---|
| 高质量 | 80-98 | 0.5（不够再 1.0） | 0.0005 | q88，4:4:4 |
| 均衡 | 再加 70-95 候选 | 满抖动 | 0.001 | q82，4:2:0 |
| 极限 | 60-90 | 满抖动 | 0.002 | q75 |

## 2. 必守规则
- 压完比原图大 → 保留原图。
- 透明通道必须保留（PNG8 + tRNS）。
- 16 位 PNG 不做有损。
- 低于高质量档一律满抖动：低抖动 + 低质量会在渐变上出色带，DSSIM 测不出来。
- 给已压文件打标记（PNG tEXt / JPG COM），再次处理自动跳过，避免反复压。
- 大批量（40 张以上）注意每张处理完释放解码内存，否则会中途失败。

## 3. 交付与验收
- 输出一张表：文件名、原大小、新大小、压缩率、质量分（SSIM）、是否保留原图。
- 挑 2-3 张最难的（渐变按钮、半透明光晕、小字）做前后局部放大对比图给用户看。
- 报告合计体积变化；不擅自替换项目里的原图，替换由用户决定。
